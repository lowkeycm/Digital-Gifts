# Customer journey

Traffic: existing customer coming from personalized preview and hosted Stripe checkout.
Offer: two full original songs, MP3, three revision rounds and a private gift page for $29 introductory price.

1. Personal preview and clear purchase offer. One primary payment action, no new intake fields.
2. Payment confirmation and immediate full playback. One active player; compare versions in compact rows. Revision form stays behind an explicit disclosure.
3. Choose favorite, prepare optional photo and personal message, then preview recipient page. The $9 printable lyric keepsake is an optional addition with an actual preview; base gift works without it.
4. Share recipient link. A successful copy/share action reveals the reaction/feedback reminder, which remains easy to find on return. Explicit gift-given is still separate; sharing never asserts delivery.
5. My songs provides return access and create-another action. Device library uses protected cookies, recovery file works across devices, optional passwordless email requires configured sender and verified mailbox.

Friction budget: no additional mandatory fields before main purchase. Prepare stage adds one optional message, existing optional photo picker and permission. Share stage one explicit send/copy action. Avoid simultaneous revision, reaction, feedback and upgrade forms. Public marketing navigation is replaced inside the private studio with My songs and the brand.

Deferred experiments: highlight selection for 60-second clips needs audio/timing analysis; photo video upsell needs a separate fulfillment product; lifecycle marketing needs approved cadence and email configuration. They are not offered as available products.

Gift page: retain the original dimensional turntable in Record, Photo and Letter options. For name, exact personal note, selected song and fully visible uploaded photo carry the message. Small controls support listening, lyrics and download. Layout previews are screenshots of the actual recipient designs.
