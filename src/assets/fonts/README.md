# Keepsake lettering

Cormorant Garamond regular, weight 400. Static TrueType instance derived from the pinned @fontsource-variable/cormorant-garamond 5.3.0 Latin WOFF2 with fontTools instantiateVariableFont at wght=400. The upstream SIL OFL is included alongside it.

The SVG preview and PDF use this same face. Direct embedding of the variable WOFF2 produced missing PDF glyphs despite a valid file, so the printable export uses this static TrueType asset. Keep it in Next.js output tracing. Verify an actual rasterized PDF after any font change.
